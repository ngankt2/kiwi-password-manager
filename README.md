# Kiwi Password releases

This repository distributes signed macOS builds of Kiwi Password. It contains no source code.

Download the latest `.dmg` from [Releases](https://github.com/ngankt2/kiwi-password-manager/releases/latest). Installed apps update themselves from `latest.json` in the latest release; every update archive is verified with the app's Minisign key before installation.
