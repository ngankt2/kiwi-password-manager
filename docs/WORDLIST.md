# Passphrase vocabulary

The bundled 7,776-word vocabulary comes from the Electronic Frontier Foundation's large word list:
https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt

It was retrieved on 23 September 2026. Dice labels are omitted because selection uses the operating system's cryptographic random source with unbiased rejection sampling. Six independently selected words provide approximately 77.5 bits of word-selection entropy before any optional formatting. No network request is made when generating a passphrase.

Background and attribution: [EFF, Deep Dive: EFF's New Wordlists for Random Passphrases](https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases).
